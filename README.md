# App
Beadandó projekt

Név: Fónad Ferenc Dávid

Neptun kód: B5C7RP

Feladat leírása:
A program egy céges flotta olajcsere-nyilvántartó asztali alkalmazás, amely grafikus felületen keresztül teszi lehetővé a cégautók olajcsere-periódusainak, kilométeróra-állásainak és dátumainak rögzítését, listázását, valamint CSV fájlba történő mentését.

Felhasználói leírás:
A program futtatásához Python 3.x környezet szükséges. Külön külső csomag telepítése nem szükséges, mivel a beépített tkinter grafikus modult használja. A program a main.py fájl elindításával futtatható.

Felépítés:
- Modul: ffd_modul.py (A saját modul, amely tartalmazza az FFD_FlottaKezelo osztályt).
- Függvények / Metódusok: ffd_elem_letrehozas, ffd_olajcsere_hozzaad, ffd_mentes_csv.
- Osztály: FFD_FlottaKezelo (A grafikus felületet és az adatok kezelését megvalósító osztály).
